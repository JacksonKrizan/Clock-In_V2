CLOCK-IN (JobSim) - PROJECT DOCUMENTATION
================================================================================

Overview:
---------
Clock-In is a multiplayer job simulation game built in Unity. Players can 
explore various career-focused mini-worlds, completing skill-based challenges 
that reflect real-world professions. The project is designed to be educational 
and engaging, showcasing the skills and tasks associated with different jobs.

Core Technologies:
------------------
- Game Engine: Unity
- Networking: Photon Unity Networking (PUN 2)
- UI: TextMesh Pro
- Scripting: C#

Main Career Worlds (Maps):
--------------------------
1. Auto Shop: Focuses on vehicle maintenance and repair (e.g., wheel attachment).
2. Chef / Kitchen: Experience the fast-paced environment of food service.
3. Airport: Scenario-based challenges in aviation logistics.
4. Game Dev / IT: Debugging and technical setup scenarios.

Controls:
---------
- WASD: Movement
- Left Shift: Sprint
- Space: Jump
- Mouse: Look Around
- Escape/Settings: Toggle Cursor / Menu

Multiplayer Features:
---------------------
- Global Lobby: Join the master server and enter the lobby.
- Room Management: Create private or public rooms with custom names.
- Map Selection: Master client chooses the starting map for all players.
- Player List: Real-time tracking of players within a room.

Project Structure:
------------------
- Assets/_Scenes: Contains all levels and the main menu.
- Assets/_Scripts/_GameImportant: Core multiplayer, player, and menu logic.
- Assets/_Scripts/[JobName]: Logic specific to each career world.
- Assets/Resources/PhotonPrefabs: Network-synced object prefabs.

Important Notes:
----------------
- Do NOT rename the "Resources" folder as it is critical for Photon instantiation.
- Player syncing uses "Unreliable On Change" for optimal performance.
- Ensure the SpawnManager is present in all gameplay scenes to handle player deaths/respawns.
