Network Engineer World - Mini Games

The jobs a network engineer does, turned into mini games you play in first person. Listed easy to hard. The first two are built, the rest are ideas to make next.

1. Packet Delivery

Status: built / playable

What it teaches: data does not travel in one big lump. It gets broken into small pieces called packets, and every packet has to reach a destination.

How you play it: a packet (a glowing cube) spawns on the floor. You pick it up and carry it across the room to the delivery goal. The catch is the floor tiles flash yellow then turn red and drop away, so you have to time your path and not fall. Deliver it and you score, then a new packet spawns.

2. Build the Route

Status: built / playable

What it teaches: routing. Data almost never goes straight to where it is going - it hops through routers along the way, and a good engineer finds the shortest path that works.

How you play it: the room has a bunch of router boxes. One lights up blue (the start) and one lights up red (the destination). You look at a box and click it, then click another box to run a cable between them. Cables can only reach so far, so you have to hop through the boxes in between. Connect the blue to the red using the fewest cables to score the most. Then a new start and destination light up and you do it again.

Below are the next four. Same skills a real network engineer needs, just new game ideas.

3. Fix the Server

Status: to do

What it teaches: troubleshooting - the real day to day job. When the network goes down you have to walk the line, find what broke, and fix it.

How you play it: you are in a server room and the connection is down. The server racks have cables running between them and one cable has come loose (its port blinks red). You walk the room, look at each rack to check it, find the unplugged end, pick it up and plug it back into the blinking port. Once every link is good the lights turn green and you score. Harder rounds have more racks and more than one loose cable.

4. Right Address

Status: to do

What it teaches: addressing. Every device on a network has its own address (an IP), and a packet only works if it is sent to the matching address.

How you play it: packets drop onto a table, each one stamped with an address. Around the room are a few delivery doors, each labeled with an address. You read the packet, carry it to the door whose label matches, and drop it in. Match it right and you score. Put it in the wrong door and it comes back. Speed it up over time so you have to read and sort quickly.

5. Traffic Control

Status: to do

What it teaches: bandwidth and congestion. Every line can only carry so much at once. Push too much down one line and it jams and starts dropping packets, so you spread the load.

How you play it: packets flow through clear pipes that run across the room, and each pipe has a lever you can pull to open or close it. When a pipe gets too full it glows red and starts leaking packets. You run between the levers, closing the jammed pipe and opening a clear one to send the flow a different way. Keep everything moving without overloading a line to keep your score climbing.

6. Security Gate

Status: to do

What it teaches: basic security. A firewall checks traffic coming in and only lets the safe stuff through while blocking anything dangerous.

How you play it: you stand at a gate where packets line up to get in. Good packets are green, bad ones are red (marked with a virus symbol). You hit the open button to let a green one through the door, and the block button to stop a red one. Let a good one through, score. Let a bad one in or block a good one, lose points. The line moves faster as you go so you have to read fast.

Plan: Packet Delivery and Build the Route are done. Do Fix the Server next since it is the most realistic. The other three are extra if there is time.
