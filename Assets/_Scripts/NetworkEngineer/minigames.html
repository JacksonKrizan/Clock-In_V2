Network Engineer World - Mini Games

List of mini games to build for this world, in order from easy to hard.

1. Packet Delivery

Status: done / playable

Teaches: data is sent in packets that have a destination

How it plays: pick up a packet and carry it to the right goal before the timer runs out.

2. Build the Route

Status: in progress

Teaches: routing - connecting nodes to find a path

How it plays: click nodes to lay cables and connect the start to the destination using the fewest connections. Cables can only be so long so you have to hop through routers.

3. Fix the Outage

Status: to do

Teaches: troubleshooting (the real day job)

How it plays: a working network has a link go down. Find the broken link and reconnect it to get traffic flowing again.

4. Address Match

Status: to do

Teaches: IP addresses

How it plays: packets come in and you sort them into the right mailbox by matching the address.

5. Bandwidth Rush

Status: to do

Teaches: bandwidth and congestion

How it plays: lots of traffic comes through. Open and close paths so no single line gets overloaded and drops packets.

6. Firewall Defender

Status: to do

Teaches: basic security

How it plays: let the good (green) packets through and block the bad (red) ones.

Goal: start with Packet Delivery and Build the Route, then add Fix the Outage. The rest are extra if there is time.
