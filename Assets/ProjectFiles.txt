Clock-In - where stuff lives
------------------------------

Notes on what each folder in Assets is actually for, so nobody has to go
clicking through everything to find one script. Add to this when you move things
around.


Scenes
------
_Scenes/    the scenes we actually use:
              _Menu      main menu + lobby
              GameDev    network engineer world
              AutoShop   auto mechanic world
              Firemap    firefighter world
              TestFeild  junk scene for trying things out

There are a bunch of other .unity files scattered around the project. Those came
with the asset packs we downloaded (demo scenes). Ignore them, they're not ours.
The old Chef/kitchen world got cut, so it's not in here anymore.


Our code
--------
_Scripts/   everything we wrote, split up by world:

  _GameImportant/   the stuff that runs no matter which world you're in
    Menu/                   main menu, lobby, room list, joining/leaving rooms
    Menu/options/           the buttons that pick which job/map to load
    PlayerImportantScripts/ moving, camera, the name above your head, spawning the player, the join tutorial panel, esc-to-quit
    Score/                  ScoreManager (the points) + Scoreboard (press T)
    UI/                     MiniGameHUD, the one shared panel every game uses

  NetworkEngineer/  network engineer world
    Packets/                carry the packet to the goal (tiles, packets, goal)
    BuildTheRoute/          wire the laptops together through routers

  FireFighting/     firefighter world - fires, the hose, putting them out, spawning hoses, the fire alerts

  AutoMap/          auto mechanic world - picking up car parts
    Arc/                    arc/throw helper bits

  _Editor/          editor-only. makes Play start from the menu instead of whatever scene you happen to have open


Photon (the multiplayer)
------------------------
Photon/             the Photon PUN plugin itself, don't touch
PhotonMenuPrefabs/  networked prefabs used by the menu
Resources/          anything Photon spawns at runtime HAS to live in here. PhotonPrefabs/ is the player controllers, the packet, the hose, the player manager


Art and map pieces (mostly downloaded packs)
--------------------------------------------
_MapBuilding/   the building blocks for the maps:
                  CarMapPrefabs   cars + garage stuff for the auto shop
                  FireAssests     firefighter models and fire map pieces
                  NetworkDev      office / server room pieces
                  MenuBuilding    set dressing behind the menu
Materials/      materials and textures
UI_Prefabs/     buttons and menu graphics
_UI/            menu backgrounds and logo art
MapPrefabsRandoms/  skyboxes, icons, leftover odds and ends
SpawnPoints/    spawn point prefabs


Other
-----
docs/                       the presentation / writeup html
ExternalDependencyManager/  a tool Photon needs to pull its dependencies. leave it alone
